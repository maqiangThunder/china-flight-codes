最容易买错的几组Common mix-ups

同一城市两个机场时，购票页面的三字码一定要点开确认，尤其北京和上海。
代码对说明
PEK / PKX北京两场。PEK 首都（老），PKX 大兴（新），两场相距 70+ 公里，别定错
PVG / SHA上海两场。PVG 浦东（国际为主），SHA 虹桥（国内 + 日韩，离市区近）
CTU / TFU成都两场。2021 年后大量航班转场天府 TFU
TAO青岛 2021 年从流亭转场胶东，三字码不变
LXA拉萨贡嘎，高高原机场，起降受天气影响大

代码含义What the codes mean

类型说明
IATA 三字码（机场）国际航空运输协会分配，全球唯一，3 个字母，旅客订票看到的都是它
IATA 二字码（航司）2 位，字母或数字组合（3U、9C、8L）。航班号 = 航司码 + 数字
ICAO 四字码空管与飞行计划使用，机场 4 字母（PEK = ZBAA），航司 3 字母（CA = CCA）
